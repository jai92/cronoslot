# CronoSlot — GitHub Actions

Sube el proyecto a la rama `cronoslot`.

El workflow `Build CronoSlot APK` se ejecutará automáticamente al hacer push a `cronoslot` o `main`, y también puede lanzarse manualmente desde Actions.

Al terminar, abre la ejecución y descarga el artefacto `CronoSlot-debug-apk`. Dentro estará `app-debug.apk`.

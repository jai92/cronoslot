# CronoSlot 4.7.0

Récords actualizados:
1. Récords absolutos: circuito -> 20 mejores vueltas de ese circuito.
2. Récords por piloto: circuito + piloto -> 20 mejores vueltas del piloto en esa pista.
3. Récords por piloto + coche: circuito + piloto + coche -> 20 mejores vueltas de esa combinación.
4. Eliminado el apartado independiente de "Últimos 20 mejores tiempos".
5. Los filtros aparecen solo cuando hay más de una opción.
6. Cada resultado muestra posición, tiempo y contexto (coche/piloto/fecha según el apartado).
